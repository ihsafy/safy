# Personal Portfolio & Research Showcase — Iqbal Hossain Safy

A high-performance, fully responsive personal portfolio website showcasing **Web Development projects, AI & Machine Learning research, Computer Vision work, and academic publications**.

## 🚀 Key Features

### Modern Dark-Mode Design
Built with modern CSS custom properties, smooth transitions, clean typography, and a professional visual system using **Plus Jakarta Sans** and **Inter**.

### Responsive Mobile Experience
Includes a touch-friendly navigation drawer with a dynamic backdrop overlay, responsive layouts, and accessible keyboard navigation with **ESC key support**.

### SEO & Metadata Optimization
Includes **Schema.org (JSON-LD) Person metadata**, Open Graph tags, semantic HTML5 structure, and optimized page metadata.

### Performance Focus
Built without heavy JavaScript frameworks or unnecessary dependencies. Uses lightweight **native ES6+ JavaScript**, Intersection Observer-based reveal animations, smooth scrolling, and optimized CSS animations.
